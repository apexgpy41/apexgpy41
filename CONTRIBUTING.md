# 🤝 Contributing Guide

First of all, thank you for considering contributing to this project!

We welcome contributions that improve the quality, security, documentation, and functionality of this repository.

---

# 📋 Before You Start

Please:

- Read the README carefully.
- Search existing Issues before creating a new one.
- Keep Pull Requests focused on one change.
- Write clean, readable, and documented code.

---

# 🚀 How to Contribute

### 1. Fork the Repository

Click the **Fork** button on GitHub.

---

### 2. Clone Your Fork

```bash
git clone https://github.com/your-username/apexgpy41.git
```

---

### 3. Create a Branch

```bash
git checkout -b feature/your-feature-name
```

Example:

```bash
git checkout -b feature/improve-readme
```

---

### 4. Make Changes

- Follow existing coding style.
- Keep commits meaningful.
- Test your changes before submitting.

---

### 5. Commit

```bash
git commit -m "Add new feature"
```

---

### 6. Push

```bash
git push origin feature/your-feature-name
```

---

### 7. Open a Pull Request

Describe:

- What changed
- Why it changed
- Screenshots (if applicable)

---

# 📖 Coding Standards

Please follow these principles:

- Clean code
- Meaningful variable names
- Proper formatting
- Comments where necessary
- Secure coding practices

---

# 🛡 Security

Never commit:

- API Keys
- Passwords
- Tokens
- Secrets
- `.env` files

---

# 🐛 Bug Reports

Before opening a bug report:

- Check existing Issues
- Include reproduction steps
- Include screenshots if possible

---

# 💡 Feature Requests

Feature requests should include:

- Problem statement
- Proposed solution
- Benefits
- Example use case

---

# ❤️ Code of Conduct

By contributing, you agree to follow the project's Code of Conduct.

---

Thank you for helping improve this project!
